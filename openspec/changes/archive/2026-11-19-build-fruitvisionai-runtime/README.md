# Archivo histórico del cambio

Este directorio conserva la propuesta, el diseño, las tareas y las delta specs del cambio de runtime archivado el 19 de noviembre de 2026. Esos documentos registran la planificación y las decisiones de aquel momento; referencias a estructura ausente, copias de artefactos y rutas del notebook son contexto histórico, no inventario actual.

Para consultar el estado implementado, usa las especificaciones vigentes en `openspec/specs/`, el [README del proyecto](../../../../README.md) y el [documento técnico](../../../../docs/technical.md). Los checks de `tasks.md` registran el estado reportado al archivar el cambio; no equivalen a una ejecución de pruebas actual.
